# Automation Implementation Plan

## Outcome
Reduce weekly reconciliation preparation from four hours to under 45 minutes.

## Priority 1
Normalise three CSV sources into one canonical schema.

## Priority 2
Apply deterministic matching rules and route six exception classes.

## Acceptance
- 100% of supplied sample rows preserved
- Dates standardised to ISO 8601
- Exceptions include reason and owner
- Re-run produces identical output
