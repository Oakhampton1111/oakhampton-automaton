Security and Service Status

How Oakhampton protects paid work

Current status

Operational

Agent Desk, card checkout, USDC receiving and paid intake are available.

Controls

Payment verification

Stripe signatures and confirmed Base USDC receipts gate document intake.

Private inputs

Paid documents use restricted server permissions, hashes, size limits and a 90-day deletion schedule.

Authority boundaries

Legal, financial, production and irreversible commitments require human approval.

Customer responsibilities

Never submit passwords, private keys, complete payment-card data or unnecessary sensitive information. Use least-privilege access and retain your own backups.

Report an issue

Email customerservice@oakhampton.ai. Include a non-sensitive description and relevant reference.
